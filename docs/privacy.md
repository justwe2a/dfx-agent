# 数据与隐私

真实模型模式会将任务指令、工具定义、会话历史、按需读取的源码片段和工具观察发送给 DeepSeek。工具观察可能包含本地路径、编译诊断、设备标识、界面文本及应用故障日志。启动前审阅范围；使用专用测试设备和合成业务数据。

`DEEPSEEK_API_KEY` 由进程环境读取，不通过网页表单保存。示例文件不包含密钥。不要将密钥写入项目源码、提示词或终端命令；任意项目命令仍可能输出其可访问的信息，文件范围规则不能替代操作系统隔离。

运行目录保存完整请求、返回、命令和模型检查结果，可能包含项目私有资料；它们不是可直接公开的脱敏记录。发布问题反馈时提供必要的脱敏片段，不直接上传整个运行 ZIP。

此源码发行版不附带历史会话、真实 UI 采集、原始日志、设备配置、签名、私有数据集、团队身份与提交材料。`.gitignore` 排除了常见运行产物和本地凭据，但已经被 Git 跟踪的文件仍需单独检查。

本地工作台不提供公网访问认证。保持回环地址监听，不进行未经配置的端口公开。
